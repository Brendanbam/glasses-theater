# Glasses Theater

Manga and movies that float in XR glasses (made for the xbx a01+ with a Legion tablet).

- **Manga**: reads the chapters you download in [Mihon](https://mihon.app) (folders or .cbz), page or webtoon strip, left-to-right or right-to-left, remembers your page and rolls into the next chapter.
- **Cinema**: a video player on a shrinkable "virtual screen" with see-through black around it. Pick it as the external player in Nuvio; it returns your position so Nuvio can resume.
- **Screen size**: L1 / R1 anywhere (50–100%).

Install and update with Obtainium: `https://github.com/Brendanbam/glasses-theater`
